# Tomo スプライト仕様 v1（ADR-0008準拠）

`internal/face/sprite.go` の正本。ドット絵を改修するときはここを先に更新し、
コードへ転写する（転写の完全性は `sprite_test.go` が行長・パレットで守る）。

キャンバス: 全ステージ共通 **16列 × 12行**（論理ピクセル）。
半ブロック描画で 16文字 × 6行になる。各ステージ2フレーム（A=基本, B=瞬き/揺れ）。

設計原則（ADR-0008 Decision 4）: ステージ間の差分は色だけに頼らず、
必ずシルエット（形）にも1点以上持たせる。S4/S5のスカーフ行が頭より
1px広いのはこのため — `NO_COLOR` でも「首まわりの膨らみ」で成長が読める。

## 実装ノート

- 全行は必ず16文字。行長とパレット外文字はテストで検証する
- 半ブロック描画: 上px=前景 `▀`・下px=背景。上だけ→`▀`（bgなし）、下だけ→`▄`、両方透明→空白
- NO_COLOR時: SGRなしで形だけ描く（上下両方→`█`、上のみ→`▀`、下のみ→`▄`）
- Frame Bの差分表記はこの文書上の省略。Goソースでは全行を明示した完全なフレームとして持つ（差分適用ロジックは作らない）
