# Tomo 端末スプライト仕様 v2（ADR-0008準拠、犬・柴犬版）

`internal/face/sprite.go` の正本。ドット絵を改修するときはここを先に更新し、
コードへ転写する（転写の完全性は `sprite_test.go` が行長・パレットで守る）。

本ファイルは**端末レンダラ（16×12・半ブロック）専用**。窓レンダラ用の
32×32高解像度資産は [SPRITES-WINDOW.md](SPRITES-WINDOW.md) が正本（ADR-0020）。
v1（とり）は2026-07-16に本ドキュメントごと差し替え — 窓のv2犬種化に端末を
追従させた。端末はフォールバックなので犬種は**柴犬のみ**
（`tomobit-face --breed` の既定と同じ。S0毛玉はもともと犬種共通）。
改修時は両資産で「同じ子に見える」こと（シルエット差分要素の一致）を確認する。

キャンバス: 全ステージ共通 **16列 × 12行**（論理ピクセル）。
半ブロック描画で 16文字 × 6行になる。各ステージ2フレーム（A=基本, B=瞬き等）。

## 設計原則（SPRITES-WINDOW.md v2 の縮約）

- **斜め45度ポーズ**: 頭が大きく左手前、体は右奥へ、白い胸と前脚が下に見える
- **グレースケール・フラット**: 塗りは窓と同じ6トーン。グラデーション禁止
- **目は塗りつぶし**（グリントなし）: 窓の2×3を半分にして**2×2**。
  **鼻は必須**（1px、両目の間の真下、白マズルの上）
- **シルエット原則の継承**（ADR-0008 Decision 4): ステージ間の差分は色だけに
  頼らず、必ずシルエット（形）にも1点以上持たせる。S4/S5のバンダナ行が
  体の輪郭より左右1px広いのはこのため — `NO_COLOR` でも成長が読める
- **アンチエイリアスなし**: 輪郭は1pxの`k`。可愛さは丸いシルエットとアニメで出す

## パレット（文字 → ANSI 256色）

窓レンダラのグレースケール6トーン（RGB）を256色グレー階調へ射影する。

| char | 意味 | 窓RGB | 256色 |
|------|------|-------|-------|
| `.` | 透明 | なし | なし |
| `k` | アウトライン | `#2E2E2E` | 236 |
| `e` | 目・鼻 | `#1A1A1A` | 234 |
| `W` | ホワイト（胸・マズル） | `#FAFAFA` | 231 |
| `l` | ライトグレー（毛玉の体） | `#D9D9D9` | 253 |
| `m` | ミッドグレー（柴の体・星・芽） | `#A6A6A6` | 248 |
| `d` | ダークグレー（バンダナ） | `#666666` | 241 |

## 成長のシルエット物語

毛玉 → あかちゃん → 芽 → 基本形 → バンダナ → 星（窓v2と同じ）

| ステージ | 形 |
|---------|---|
| S0 **毛玉** | 犬種共通のまんまるふわふわ。寝ている毛玉に犬種は見えない |
| S1 あかちゃん | 頭でっかちの子犬。体は詰まった小ささ、尻尾はまだ点 |
| S2 こども | S3から胴2行を詰めた小さい体+頭に芽（導出規則） |
| S3 わかもの | 基本形（下記正本） |
| S4 おとな | S3+バンダナ（導出規則） |
| S5 あいぼう | S4+星2つ（Bで位置交替、導出規則） |

## S5 あいぼう（S4+星、導出規則）

星（1px、`m`）を2つ、シルエット外に。Frame Bで位置が入れ替わる:

| | 左 | 右 |
|--|-----|-----|
| A | (r2,c0) | (r0,c12) |
| B | (r0,c0) | (r3,c12) |

Frame A（S4Aに星2px追加）/ Frame B（S4Bに星2px追加）。

## Frame B 共通規則（瞬き）

目2行のうち**上段の`e`を体色`m`へ**置換（下段が残り、伏し目になる）。
鼻の`e`は目行の外にあるため影響しない。目行の上端:

| ステージ | 行 |
|---------|----|
| S1 | r6 |
| S2 | r6 |
| S3/S4/S5 | r4 |

追加動作: S0=毛並みの揺れ、S2=芽の揺れ、S5=星の入れ替わり（各節参照）。

## 実装ノート

- 全行は必ず16文字。行長とパレット外文字はテストで検証する
- 半ブロック描画: 上px=前景 `▀`・下px=背景。上だけ→`▀`（bgなし）、下だけ→`▄`、両方透明→空白
- NO_COLOR時: SGRなしで形だけ描く（上下両方→`█`、上のみ→`▀`、下のみ→`▄`）
- Frame Bの差分表記はこの文書上の省略。Goソースでは全行を明示した完全なフレームとして持つ（差分適用ロジックは作らない）
- ステージ名も犬化に追従: S0=毛玉、S1=あかちゃん（`face.StageName`）
