# Tomo 窓用スプライト仕様 v2（ADR-0020準拠、犬種・斜めポーズ版）

`internal/facewin/sprite32.go` の正本。Tomoのスプライト資産はここが唯一の正本 —
端末用16×12資産（SPRITES.md）は [ADR-0025](../decisions/ADR-0025-face-autolaunch.md)
で端末レンダラごと廃止した。
v1（正面ポーズ・ねこ/とり/いぬ）は2026-07-16に本ドキュメントごと差し替え
（経緯はADR-0020の改訂履歴参照）。

キャンバス: 全ステージ共通 **32列 × 32行**（論理ピクセル）。
描画は整数拡大のnearest-neighborのみ（既定4倍=128px角）。背景は透過。
各ステージ2フレーム（A=基本, B=瞬き等）。

## 設計原則

- **斜め45度ポーズ**（本人提供の参考画像準拠）: 頭が大きく左手前、体は右奥へ、
  白い胸と前脚が下に見える。犬種の個性は耳と尻尾と毛並みの形だけで書き分ける
- **グレースケール・フラット**: 塗りは6トーンのグレーのみ。グラデーション禁止。
  現行16×12の雰囲気（フラット塗り・太い暗色アウトライン・チャンキー）を継承
- **目はグリントなしの塗りつぶし2×3**（本人指示 2026-07-16）。
  ハイライト用の白`w`はパレットごと廃止。**鼻は必須**（2×2、両目の間の真下、
  白マズルの上 — 鼻がないと怖くなることが確認済み）
- **シルエット原則の継承**（ADR-0008 Decision 4）: ステージ間の差分は必ず形に持たせる
- **アンチエイリアスなし**: 輪郭は1pxの`k`。可愛さは丸いシルエットとアニメで出す
- **明暗両対応**: シルエット外に出る要素（星）は`m`固定。
  アウトラインは純黒でなく`#2E2E2E`
- 表情（はてな/ねむい）はオーバーレイ記号（ADR-0008 Decision 3）。本体分岐なし

## パレット（文字 → RGB）

グレースケール6トーン。グリント`w`は廃止済み。

| char | 意味 | RGB |
|------|------|-----|
| `.` | 透明 | なし |
| `k` | アウトライン | `#2E2E2E` |
| `e` | 目・鼻 | `#1A1A1A` |
| `W` | ホワイト（胸・マズル・ポメの体） | `#FAFAFA` |
| `l` | ライトグレー（レトリーバーの体） | `#D9D9D9` |
| `m` | ミッドグレー（柴の体・星・芽） | `#A6A6A6` |
| `d` | ダークグレー（垂れ耳・鼻先・バンダナ） | `#666666` |

## 成長のシルエット物語

毛玉 → 子犬 → 芽（+ポメは尻尾が開く）→ 基本形 → バンダナ → 星

| ステージ | 形 |
|---------|---|
| S0 たまご改め**毛玉** | 犬種共通のまんまるふわふわ。寝ている毛玉に犬種は見えない |
| S1 あかちゃん | 頭でっかちの子犬。ポメの羽毛尻尾はまだ開いていない |
| S2 こども | S3から胴4行を詰めた小さい体+頭に芽（導出規則） |
| S3 わかもの | 基本形（下記正本） |
| S4 おとな | S3+胸のバンダナ（導出規則） |
| S5 あいぼう | S4+星2つ（Bで位置交替、導出規則）。瞳の輝き規則はグリント廃止に伴い削除 |

## S2 こども（S3からの導出規則）

1. S3 Frame Aをベースに胴を**4行削除**する
   （柴/レト: r19〜r22 ／ ポメ: r17〜r20。ポメは羽毛尻尾ごと縮む）
2. 上に空行4を挿入（接地線を維持したまま背が低くなる）
3. 芽（`m` 2px）を頭上に植える。Frame Bで葉が反対側へ揺れる:

| 犬種 | 茎 | 葉A | 葉B |
|------|----|-----|-----|
| 柴犬 | (r9,c11) | (r8,c12) | (r8,c10) |
| レトリーバー | (r7,c10) | (r6,c11) | (r6,c9) |
| ポメラニアン | (r8,c10) | (r7,c11) | (r7,c9) |

## S4 おとな（S3+バンダナ、導出規則）

1. 首下の2行を `d` の帯に置換（柴/レト: r17〜r18のc5〜c16 ／ ポメ: r15〜r16のc4〜c16）
2. 胸の三角結び: 帯の直下3行、c8〜c13 → c9〜c12 → c10〜c11 を `d` に

## S5 あいぼう（S4+星、導出規則）

星（プラス型5px、`m`）を2つ。Frame Bで位置が入れ替わる。座標は星の上端px:

| 犬種 | A左 | A右 | B左 | B右 |
|------|-----|-----|-----|-----|
| 柴犬 | (r6,c2) | (r4,c20) | (r3,c2) | (r8,c20) |
| レトリーバー | (r2,c1) | (r5,c23) | (r20,c1) | (r2,c23) |
| ポメラニアン | (r4,c1) | (r3,c19) | (r8,c1) | (r6,c19) |

## Frame B 共通規則（瞬き）

目3行のうち**上下行の`e`を体色へ**置換（中央行が残り、閉じ目の横線になる）。
鼻の`e`は目行の外にあるため影響しない。目行の上端:

| ステージ | 柴/レト | ポメ |
|---------|--------|------|
| S1 | r17 | r17 |
| S2 | r15 | r14 |
| S3/S4/S5 | r11 | r10 |

追加動作: S0=毛並みの揺れ、S2=芽の揺れ、S5=星の入れ替わり（各節参照）。

## 実装規約

S2/S4/S5とFrame Bは上記の**導出定義が正本**。Goソースは規約通り全ステージ・
全フレームの完全なグリッドリテラルを持ち（実行時の差分適用ロジックは作らない）、
テストが導出規則を再適用して両者の一致を検証する。参照実装は
`tools/spritegen/`（`breeds34.py`=正本グリッド、`stages34.py`=展開・検証・シート出力）。
