# ADR-0049: 沈黙は同意ではない — 残量観測を既定OFFにする

## Context

ADR-0044は残量観測の経路Aを採用し、実装をstatus・機械view・GUIへ配線した。
あのADRの判断は**一人の機械の上で**下されている。文中の言葉を引くと、経路Aは
「所有者許可の下で実測済み」だった。

これをOSSとして公開すると、前提が壊れる。

- 読むのは **macOS Keychain の資格情報**（`Claude Code-credentials-<hash>`）
- 叩くのは **ベンダーが文書化していない** usage 端点（`oauth-2025-04-20` beta ゲート）
- そして公開後、これは `tomobit status` を打った**全員の機械で無言で走る**

所有者の許可は、所有者の機械にしか及ばない。他人の機械で同じことをするのに、
その許可は使えない。ADR-0044の技術的判断（PTYスクレイプ却下・ブラウザcookie読み却下・
codexbar依存却下・取れないときは「不明」）はどれも正しいままだが、**既定値だけが
一人用の設定のまま公開されようとしていた。**

ここには経験主権（ADR-0018）との整合の問題もある。「主権＝所有者だけが動かせる」を
掲げながら、所有者が一度も同意していない資格情報の読み取りが既定で走るなら、
その主張は自分の実装に否定されている。

## Decision

### 1. 既定はOFF。`config.quota_observe` が明示的に `true` のときだけ観測する

`Config.QuotaObserve *bool` を追加する。他のポインタboolと**非対称に、nil = OFF**。

`split_protocol`（ADR-0028）は nil = ON だった。そちらは「キーが生える前に書かれた
configを黙って降格させない」ことが正しかったからで、判断の質にしか影響しない。
こちらは資格情報と外部端点に触る。**降格の事故より、無言の実行の事故のほうが重い。**

解決は `Config.QuotaObserveEnabled()` に置く（cmd側ではなく）。CLIも将来の
レンダラも同じ答えを読む必要があり、既定の複製は「沈黙は同意ではない」を
取り違える場所を二つに増やすだけだから。

### 2. 無効のときは行を出さない。「不明」を使わない

無効時 `collectQuotaFn` は nil を返す。**「不明」は使わない。**

ADR-0044 Decision 5 で「不明」は「観測を試みたが分からなかった」の語として定義した。
訊いてもいないのにその語を出せば、**あの view で唯一正直な言葉が嘘になる。**
無効は無音であるべきで、無知を装うべきではない。

### 3. `tomobit setup` が訊く。質問文にコストを書く

`askQuotaObserve` を配線の対話に足す（ADR-0021の器に載せる。新しい口は作らない）。

質問文には、onにすると**何が起きるか**を書く — Keychainを読むこと、非公式な端点で
あること、いつ消えてもおかしくないこと。**理解されていないopt-inは同意ではない。**
コストをADRの中に置いたままにせず、訊く場所で言う。

### 4. ADR-0044は撤回しない

経路Aの選択、プロファイル依存のKeychainサービス名の導出、429が401に化ける実測、
「推定値を出さない・決定則に混ぜない」——すべて有効なまま。
**変えたのは既定値ひとつだけ。**

## Consequences

- **既存の機械も一度OFFに落ちる。** 所有者を含めて、`tomobit setup` を再実行するか
  `~/.tomobit/config.json` に `"quota_observe": true` を足す必要がある。
  これは意図的な非互換で、黙って有効のままにすると「公開前から使っていた人だけが
  同意なしで有効」という最悪の非対称が残る。**自分の機械にも同じ規則を適用する。**
- GUIサイドバーのUsageセクションは、無効時に残量ゲージを持たない
  （tomobit-gui ADR-0006 の「観測できない枠にはバーを引かない」がそのまま効く）。
  Provider別の**利用実績**はメモリペインに残る — あれは台帳由来で、観測ではない
- `hasAnyOtherFieldSet` に1件追加。`Config` のフィールド数を固定するテストが
  更新漏れを捕まえる（実際にこの変更で発火した）
- 却下: 環境変数 `TOMOBIT_QUOTA_OBSERVE` による上書き。他の配線と違い、
  これは「セッション単位で切り替えたい」種類の設定ではない。同意は恒久的か、無いか

## 原則

> **沈黙は同意ではない。**
> 判断の既定は最良の推測でよいが、他人の資格情報に触る既定は、
> 推測であってはならない。
